# 学生成绩判断器

## 📌 项目介绍
Java控制台程序，输入姓名与成绩，自动判定优秀/良好/中等/及格/不及格。

## ✨ 功能
- 输入姓名与分数
- 90–100 → 优秀
- 80–89 → 良好
- 70–79 → 中等
- 60–69 → 及格
- 0–59 → 不及格
- 校验成绩范围 0–100
-自动判定是否号码错误和判定是否里面有没有字母
-有效分数
-总分
-平均分
-最高分
-最低分
-及格人数
-及格率
-优秀率（>=80）
-不及格率（<40）
-中位数 
-标准差 
-分数段直方图
-各等级人数和占比

## 🛠️ 运行方式
```bash
javac StudentPerformance.java
java StudentPerformance
